# MCU platform profiles

Create one profile per MCU family. Each profile must document exact part/package, vendor documentation, supported compiler/version, SDK/HAL acquisition and licensing, startup/linker configuration, CI build command, and programming/debug requirements.

Planned families:
- STM32
- TI MSPM0
- TI C2000
- TI MSP430
- ESP32
- Other MCU families as needed
